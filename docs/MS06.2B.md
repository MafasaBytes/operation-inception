## Approved drive and contact gate

Downward travel is positive. At first actual piston contact, record both actual
and commanded heights and their tick/time. Both after-contact travel values start
at zero, without crediting an earlier free approach or command gap:

```text
achieved_travel = max(0, first_achieved_height - achieved_height)
commanded_travel = max(0, first_commanded_height - commanded_height)
debt = clamp(commanded_travel - achieved_travel, 0, ramp_distance)
D = clamp((achieved_travel + debt) / ramp_distance, 0, 1)
L = C * D * min(1, weighted_contacts / 4)
```

C=1 only in compression mode for the current piston-connected graph, otherwise 0.
Neighbor, piston, side-wall and floor weights remain 1/2/1/1. Ramp distance is
explicit per scenario; conformance uses .16 for reference radius .08. No fixture
injects debt, load or qualifying time. Debt is recomputed from current anchored
positions, never accumulated or manually reset. Held commands cannot keep
increasing debt indefinitely. During catch-up, achieved travel increases and debt
decreases through the same formula.

A discrete first contact may have slightly different commanded/actual heights;
each has its own recorded zero anchor. Consequently debt is an after-contact
travel discrepancy, not necessarily the unanchored raw height gap. This convention
is visible in the first-contact event and every tick diagnostic.

## Versioned motion and settling policy

| Parameter/policy | PB-1.2 value |
| --- | --- |
| Fixed active and settling clock | 120 Hz |
| Physics substeps | 4 per tick, configurable integer 1..8 |
| Gravity | 1.2 world units/s² downward |
| Damping | velocity factor exp(−8×substep_seconds) |
| Projection | Existing ordered circle/boundary solver, maximum 64 passes per trial |
| Catch-up policy | `bounded-contact-rollback-v1` |
| Maximum piston speed | .40 world units/s |
| Maximum piston substep | min(speed×dt, smallest inside radius/4) |
| Settling speed tolerance | .002 world units/s |
| Settling penetration tolerance | 1e−6 world unit |
| Continuous settling qualification | .25 s / 30 complete intervals |
| Settling ceiling | 20 s / 2400 ticks; negative fixture lowers this to 3 ticks |
| Wall capacity | 2.5, fixed for this versioned slice |

The actuator cannot move through unresolved disk geometry. Each substep trials
only a bounded move toward the current command. If compression cannot resolve,
it can still close the real free gap to the highest ball surface, subject to a
valid contact pose; otherwise it rolls back that small piston move. This prevents
a piston hovering just outside contact tolerance. It does not retry the entire
growing command gap or teleport after a crush. Later bounded substeps can catch
up when resistance clears.

Commands faster than this policy's free-motion capacity are invalid. Otherwise
the speed cap itself could masquerade as bed resistance and manufacture debt.
The rate check includes the generation-3 minimum-radius substep cap. Tests prove
free commanded motion tracks actual motion with zero debt.

Piston projection is followed by damped gravity integration and ordered constraint
projection in each substep. Recorded velocities derive from actual corrected
motion. Gravity also operates during active compression, so a prepared bed does
not become a floating visual arrangement. This remains stylized disk dynamics,
not a mass/material or hydraulic engineering model.

Preparation retracts the piston to configured chamber height, runs gravity and
damping with all split/crush/wall clocks disabled, and preserves identities,
lineages, generations and radii. Both speed and penetration must qualify at
consecutive observations for 30 full intervals. Frozen starting state includes
balls, contacts, walls and retracted height; its SHA-256 and full preparation
history are recorded. Active time starts at 0 only after success. The configured
active starting piston pose must not intersect the settled bed.

Non-finite/severe geometry, unresolved settling penetration or exhaustion of its
finite time/event budget is an invalid setup, never a gameplay draw. No hidden
preload or birth occurs during preparation. The successful floor-column fixtures
settle in .258333 s; falling-body fixtures provide separate nontrivial gravity
settling proofs. All derived settled hashes are included in the conformance file.

## Wall-section arithmetic and unchanged thresholds

Each side has four fixed equal-height sections. For a circle against a vertical
wall the actual contact point is (wall_x, ball_y); that point assigns the section.
Each contribution records ball ID, point, inward normal, L, radius, reference
radius and arithmetic. Left/right are separate; floor and piston do not count.
Directionality here means a genuine side-wall contact with its horizontal normal;
there is no unapproved extra cosine factor or claim of physical force units.

```text
contribution_i = L_i * radius_i / reference_radius
W_section = clamp(sum(contribution_i) / 2.5, 0, 1)
```

Thresholds remain: split .50<=L<.90 for .30 s, crush L>=.90 for .15 s,
wall strain W>=.60, rupture W>=.80 for .40 s, final containment stable for .60 s.
Generation 3, live 96, semantic 20,000, active 18-second and non-progress bounds are
inherited. Numeric threshold tolerance remains 1e−12; contact tolerance is 1e−6.

One immutable post-physics contact/load/wall snapshot advances and latches clocks.
Structural order remains **crush → rupture → split**, then stable identity order.
A crush cannot cancel that tick's completed rupture qualification. The log adds
only settling, first-contact, blocked/unblocked, debt-episode and wall-qualification
facts; detailed commanded/achieved/debt histories live in frozen tick samples.
Events include complete before/after states and contiguous stable sequence IDs.

Rupture opens its actual section, stops actual piston and command advancement,
vents loads and clocks, and uses the inherited .40-unit/s outward release for
qualified balls fitting that opening. A full-disk crossing creates each escape.
Release resolves after exactly .60 s. Remaining balls are retained; debt diagnostics
are not secretly reset to fabricate relief. A global ceiling interrupting release
remains an unresolved draw with the genuine opening retained.

## Technical limits and next approval gate

Load/debt is a normalized stylized proxy. A numerical constraint-budget failure
can still act as resistance; this is not proof of physical force transmission.
Closely packed larger beds may settle slowly, fail explicitly or have sensitive
contact graphs. The conservative speed guard constrains authored command rates.
Private PB-1.1 kernel reuse requires compatibility tests on future edits. Numeric
byte identity is promised in the same environment, not across all platforms.

The miniature fixtures prove reachability, not the earlier whole-bed activity,
isolated-teaching, event-density, late-rupture or robustness requirements. Those
still need a newly authored PB-1.2 scenario and audit. Existing render/audio
adapters have not been updated to consume this version. No creative acceptance
or satisfying phone experience is claimed.

PB-1.2 is technically ready to support a **separately approved prototype build**.
Do not render, synthesize production audio, begin MS06.4 or publish without another
PO approval. Historical PB-1.1 artifacts and the closed MS06.3B record remain frozen.

Verification completed: **13 focused tests and 109 full-suite tests passed**.
All 14 PB-1.2 complete simulation/replay byte comparisons and all 16 preserved
PB-1.1 scenario-record bytes match. The final JSON is canonical and all embedded
